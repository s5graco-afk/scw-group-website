Available coding functions depend on the vehicle equipment and software version. Tap any option to see details.

General

Auto Start/Stop memory or default OFF
The vehicle can remember the last Auto Start/Stop setting, or the function can be configured to start switched off while remaining available from the button.
Disable Auto Start/Stop activation in ECO PRO
Prevents ECO PRO mode from automatically enabling Auto Start/Stop. Requirements: Availability depends on the vehicle software version.
Sport+ mode
Adds Sport+ to the available driving modes where supported. Sport+ combines a sport-oriented vehicle setup with reduced stability-control intervention.
Sport automatic transmission
Enables the sport transmission configuration on compatible vehicles, changing shift behavior in sport modes. Requirements: Some vehicles already have this configuration from factory.
Launch Control
Enables the supported launch-control function for rapid standing starts. Requirements: Availability depends on engine, transmission and software level.
Start vehicle in ECO PRO
Changes the default driving mode at engine start from Comfort to ECO PRO where supported.
Disable seat-belt reminder
Disables selected acoustic/visual seat-belt reminders without physically bypassing the restraint detection system.
Disable horn confirmation when locking with engine running
Removes the short horn warning produced when the running vehicle is locked from outside on supported software versions.
One-touch window closing with door open
Allows automatic window closing to continue when a door is open, where supported.
AUTO climate button without forced A/C
Removes the link that automatically switches the air-conditioning compressor on when AUTO climate mode is selected.
Fog lights off with high beam
Configures the fog lights to switch off when high beam is activated, where the lighting hardware supports it.
Maximum DRL brightness in additional light modes
Changes daytime-running-light brightness behavior in supported lighting modes.
Cornering lights via fog lamps
Uses the corresponding fog lamp as a cornering light at low speed when steering, on compatible vehicles.
Rear position lights with daytime running lights
Enables rear position lights together with the daytime running lights.
Door-handle lighting in reverse
Activates exterior door-handle illumination when reverse is selected in darkness. Requirements: Requires compatible lighting equipment.
Disable headlight washers
Disables the headlight washer function on vehicles equipped with the system.
Fold mirrors without delay
Reduces the hold time required on the remote or door handle to fold the mirrors. Requirements: Requires power-folding mirrors.
Reverse mirror dip angle
Adjusts the passenger-side mirror dip angle used while reversing on compatible vehicles.
Turn audio off when driver door opens
Stops multimedia audio when the engine is off and the driver door is opened.
LIM function instead of SET
Changes the supported steering-wheel SET button function to the speed-limiter function. Requirements: Requires compatible cruise-control equipment.
Oil service interval adjustment
Adjusts the base oil-service interval where supported. Final service calculation can still vary according to vehicle operating conditions.

Instrument Cluster

Digital speedometer
Enables a digital vehicle-speed display in compatible instrument clusters.
Traffic Sign Recognition activation
Activates road-sign recognition and display in the instrument cluster. Requirements: Requires navigation maps and the necessary permission/activation in the camera control unit.
M Performance logo
Changes the supported instrument-cluster startup graphic to an M Performance style. Requirements: Requires a compatible instrument cluster.

Multimedia & iDrive

BMW M startup animation
Changes the supported multimedia startup animation from the standard BMW graphic to an M-style graphic. Requirements: Requires a compatible BMW head unit.
Video in Motion
Allows supported video sources to remain available while the vehicle is moving. Use only where lawful and without distracting the driver.
Additional USB video codecs
Enables additional supported video formats for playback from USB media. Requirements: Requires a compatible NBT-family head unit.
ID5 to ID6 interface
Changes a compatible NBT EVO system from the ID5 menu presentation to the newer ID6-style interface. Requirements: Requires NBT EVO.
Screen Mirroring
Enables supported Android screen mirroring on compatible BMW multimedia hardware. Requirements: Requires compatible hardware/software.
DRL on/off option in iDrive
Adds the supported daytime-running-light switch to the vehicle lighting settings.
Acoustic lock/unlock confirmation
Adds the supported menu option for audible locking and unlocking confirmation. Requirements: Requires compatible factory alarm hardware.
Rolls-Royce warning sounds
Changes compatible interior notification and parking-warning sounds to the Rolls-Royce sound set. Requirements: Requires a compatible head unit.
BMW i warning sounds
Changes compatible interior notification sounds to the BMW i sound set. Requirements: Requires a compatible head unit.
M-style sport displays
Enables or changes compatible sport-display graphics to an M-style presentation.
Tyre temperature display
Adds tyre-temperature information alongside pressure information where supported. Requirements: Requires compatible tyre-pressure monitoring hardware.
Rear camera trailer-hitch zoom
Adds the supported rear-view-camera zoom function for more precise positioning. Requirements: Requires a factory-compatible rear camera.
Apple CarPlay activation
Activates Apple CarPlay on compatible BMW multimedia systems. Full-screen mode can also be enabled when supported. Requirements: Requires compatible head unit, software and wireless hardware.
Full-screen Apple CarPlay
Changes an existing compatible CarPlay installation from split-screen presentation to full-screen mode. Requirements: Requires an already supported CarPlay-capable system.
